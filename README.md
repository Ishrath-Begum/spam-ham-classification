#  Spam/Ham Classification Using NLP

## Overview

Developed an **NLP-based text classification model** to identify messages as **Spam or Ham** using **TF-IDF** and **Multinomial Naive Bayes**.

## Technologies Used

- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Google Colab

## Project Workflow

- Text preprocessing and corpus preparation
- Train-test split
- TF-IDF feature extraction
- Multinomial Naive Bayes model training
- Spam/Ham prediction
- Model evaluation

## Model Performance

| Metric | Score |
|---|---:|
| Accuracy | **99%** |
| Weighted Precision | **99%** |
| Weighted Recall | **99%** |
| Weighted F1-Score | **99%** |

## Key Observations

- Achieved **99% accuracy** on the test dataset.
- Achieved a **weighted F1-score of 0.99**, indicating strong overall classification performance.
- **Ham classification achieved 100% recall**.
- Spam classification achieved **97% precision, 93% recall, and 95% F1-score**.

## Conclusion

The Multinomial Naive Bayes model demonstrated **excellent performance in Spam/Ham classification**, with particularly strong results in identifying Ham messages while maintaining high precision and recall for Spam detection.
